### 정의

- **정렬된 순서를 유지하는 Map** 구현체
- Key를 기준으로 항상 **정렬 상태** 유지
- 내부 구현: **Red-Black Tree** (자가 균형 이진 탐색 트리)
- Java `java.util.TreeMap` / Kotlin에서도 동일하게 사용

### HashMap과의 차이

- **HashMap**: 순서 없음, 조회/삽입 평균 `O(1)`
- **TreeMap**: 정렬 순서 유지, 조회/삽입 `O(log n)`
- 정렬이 필요 없으면 HashMap이 빠름 → TreeMap은 **정렬·범위 조회가 필요할 때만** 선택

### 핵심 연산 (모두 O(log n))

- `firstKey()` / `lastKey()`: 최소·최대 Key
- `ceilingKey(k)`: k **이상**인 가장 작은 Key
- `floorKey(k)`: k **이하**인 가장 큰 Key
- `higherKey(k)`: k **초과**인 가장 작은 Key
- `lowerKey(k)`: k **미만**인 가장 큰 Key
- `subMap(a, b)`: 범위 [a, b) 조회

### 어떤 경우에 쓰는가

- **범위 조회**: "특정 값 이상/이하의 Key를 빠르게 찾아라"
- **정렬 유지 삽입/삭제**: 삽입할 때마다 자동 정렬 유지가 필요할 때
- **경계값 탐색**: 특정 값에 가장 가까운 원소 (ceiling/floor)
- 예: 좌표 압축, 스케줄링에서 가장 가까운 빈 시간 찾기, 구간 관리

### 우선순위 큐와의 구분

- **PQ**: 최솟값/최댓값 **하나**만 빠르게 꺼냄. 임의 원소 탐색·삭제 불가
- **TreeMap**: 정렬 전체를 유지하며 **임의 위치 탐색·삭제·범위 조회** 가능

> 
> ## 이진 탐색 트리 (BST) 기초
> 
> ### 정의
> 
> - 각 노드가 최대 **2개의 자식**을 가지는 트리
> - **정렬 규칙**: 모든 노드에서
>     - **왼쪽 서브트리**의 모든 값 < 현재 노드 값
>     - **오른쪽 서브트리**의 모든 값 > 현재 노드 값
> 
> ### 예시 구조
> 
> `8`을 루트로 `4, 12`를 삽입하면:
> 
> - `4 < 8` → 왼쪽 자식
> - `12 > 8` → 오른쪽 자식
> 
> ```
>     8
>    / \
>   4   12
> ```
> 
### > 탐색 방식
> 
> - 찾는 값이 현재 노드보다 작으면 → 왼쪽으로
> - 크면 → 오른쪽으로
> - 매 단계마다 탐색 범위가 **절반**으로 → `O(트리 높이)`
> 
> ### 핵심: 시간복잡도는 "높이"에 달렸다
> 
> - 균형 잡힌 트리: 높이 `log n` → 탐색 `O(log n)`
> - 한쪽으로 치우친 트리: 높이 `n` → 탐색 `O(n)`
